# Security policy

The current 0.1.x prerelease is supported on a best-effort basis. It has not been independently audited. See [the threat model](docs/SECURITY.md) and [verification results](docs/TEST_RESULTS.md) for scope and known testing gaps.

Report security vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/thegreatkingbear/codex-quota-tray/security/advisories/new). Do not include authentication tokens, credentials, raw Codex responses, or personal account information. If private reporting is unavailable, open an issue requesting a private contact channel without disclosing exploit details.

Ordinary bugs and feature requests can be filed in GitHub Issues.
