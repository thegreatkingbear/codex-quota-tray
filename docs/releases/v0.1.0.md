# Codex Quota Tray v0.1.0

First public **prerelease** for Windows 11 x64. MIT licensed, portable, and self-contained: no separate .NET installation or administrator privileges required.

## Download and run

1. Download **CodexQuotaTray-v0.1.0-win-x64.zip** from the release assets (not GitHub's Source code ZIP).
2. Extract the entire ZIP to a permanent folder.
3. Run **CodexQuotaTray.App.exe** from that folder.
4. To see real usage, install and sign in to official Codex. If discovery does not find it, select your trusted official `codex.exe` in Settings → Advanced.

You can explore the interface without an account using Settings → Advanced → Demo mode. Start with Windows is optional and off by default.

## Included

- Large remaining-percentage tray digits and a colored perimeter graph.
- Details for each server-reported quota, including its period and local reset time.
- Auto selection of the shortest quota period, or a specific quota chosen in Settings.
- Windows light/dark theme support, compact actions, and content-sized windows.
- Configurable refresh intervals and optional current-user startup registration.
- Sample mode, explicit stale/error states, and no credential handling by this app.

## Verification and limitations

Windows Release build and 100 automated checks pass. Live Codex usage and sample UI have been tested on the development machine. Clean-account testing, full DPI/multi-monitor coverage, sleep/resume, and Explorer restart testing remain incomplete. This is a preview, not a fully certified stable release.

The executable is **unsigned**, so Windows may show an unknown-publisher warning. No automatic updater is included. The app is independent and not endorsed by OpenAI. It reads limits through the user's installed Codex process; that process may contact OpenAI. Codex itself and user credentials are not bundled.

`SHA256SUMS.txt` contains the ZIP checksum. `BUILD-INFO.txt` identifies the source commit and build environment; `FILES-SHA256.txt` inside the ZIP lists packaged file hashes. Checksums provide integrity checking, not proof of independent auditing or bit-for-bit reproducibility. Bundled Microsoft runtime components retain their own notices and licenses.
