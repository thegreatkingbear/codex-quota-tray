# Codex Quota Tray v0.1.1

Windows 11 x64 **prerelease** with a fixed-folder installer and manual updates. The .NET runtime is included; no administrator privileges are required.

## Install or update

1. Download **CodexQuotaTray-v0.1.1-win-x64.zip** and extract the entire ZIP.
2. Exit any running Codex Quota Tray using its tray menu.
3. Double-click **Install.cmd** and confirm installation.
4. Open **Codex Quota Tray** from the Start menu afterward. Do not run the EXE inside the downloaded `app` subfolder.

Every version installs to **`%LOCALAPPDATA%\Programs\CodexQuotaTray`**. For future updates, exit the app and run Install.cmd from the new extracted ZIP. Existing preferences are preserved. If startup was already enabled, its path is updated; otherwise it remains off. Windows startup-blocking preferences are not overridden.

## Fixes

- A consistent executable path prevents additional per-version tray entries during normal installed updates.
- Existing v0.1.0 portable users can use the same installer to migrate. Identified old Quota Tray tray entries are backed up and removed; other applications' entries are preserved. Reopen Windows Settings to refresh its list.
- A Start menu shortcut always points to the fixed installation.
- Payload files are verified before installation. Updates are staged before replacing the old directory; old application files remain in a `CodexQuotaTray.backup-*` sibling folder for recovery. Settings remain in `%LOCALAPPDATA%\CodexQuotaTray`.

The installer does not delete old portable folders or their shortcuts. After installation succeeds, stop using those copies; you can remove them yourself. Registry backups are in `%LOCALAPPDATA%\CodexQuotaTray\maintenance-backups`. After confirming an update works, you may delete its old application backup folder.

## Verification and limitations

100 application checks and 15 Windows PowerShell installer checks cover installation, replacement, corrupt/traversing manifests, startup migration, and scoped tray cleanup. This remains an unsigned preview; Windows may show an unknown-publisher warning. Clean-account testing, full DPI/multi-monitor coverage, sleep/resume and Explorer restart coverage remain incomplete. Enterprise policy can prohibit unsigned scripts; the installer does not change persistent execution policy or Group Policy.

The launcher uses a process-scoped PowerShell execution policy for its bundled installer only. There is no automatic download or updater. Real usage requires a signed-in official Codex installation. Codex and credentials are not bundled. This independent MIT-licensed app is not endorsed by OpenAI.

`SHA256SUMS.txt` verifies the ZIP; `BUILD-INFO.txt` records the source revision and build environment. These provide integrity and provenance information, not independent audit or bit-for-bit reproducibility guarantees.
